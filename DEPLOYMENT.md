# 🚀 Deploying DayFlow — Vercel (Frontend) + Render (Backend + DB)

## Architecture

```
Users → Vercel (Angular) → Render (Spring Boot) → Render PostgreSQL
```

---

## Step 1 — Push to GitHub

```bash
git add .
git commit -m "chore: production deployment setup"
git push origin main
```

---

## Step 2 — Deploy Backend on Render

1. Go to **https://render.com** → Sign in with GitHub
2. Click **"New +"** → **"Blueprint"**
3. Select your repository → Render will detect `render.yaml` automatically
4. Click **"Apply"** — Render will create:
   - A **Web Service** (`dayflow-backend`) running Spring Boot
   - A **PostgreSQL database** (`dayflow-postgres`) — FREE tier
5. Wait ~5 minutes for the first build

**Your backend URL will be:**
```
https://dayflow-backend.onrender.com
```

---

## Step 3 — Update Frontend with Your Backend URL

Open `frontend/src/environments/environment.prod.ts` and replace `YOUR_RENDER_APP_NAME`:

```typescript
export const environment = {
  production: true,
  apiBaseUrl: 'https://dayflow-backend.onrender.com'  // ← your actual Render URL
};
```

Commit and push:
```bash
git add frontend/src/environments/environment.prod.ts
git commit -m "fix: update production API URL"
git push origin main
```

---

## Step 4 — Deploy Frontend on Vercel

1. Go to **https://vercel.com** → Sign in with GitHub
2. Click **"Add New Project"** → Import your repository
3. Set the **Root Directory** to `frontend`
4. Leave build settings as-is (Vercel reads `vercel.json`)
5. Click **"Deploy"**

**Your frontend URL will be:**
```
https://dayflow-frontend.vercel.app   (or similar)
```

---

## Step 5 — Set CORS on Render

After Vercel gives you a URL, go to your Render backend service:
- **Environment** tab → Edit `ALLOWED_ORIGINS`
- Set it to your Vercel URL:
  ```
  https://dayflow-frontend.vercel.app
  ```
- Render will auto-redeploy

## Environment Variables Summary (Render)

| Variable | Value |
|---|---|
| `DB_URL` | Auto-set from linked database |
| `DB_DRIVER` | `org.postgresql.Driver` |
| `JPA_DIALECT` | `org.hibernate.dialect.PostgreSQLDialect` |
| `H2_CONSOLE_ENABLED` | `false` |
| `JWT_SECRET` | Auto-generated by Render |
| `ALLOWED_ORIGINS` | `https://your-app.vercel.app` |

## ⚠️ Notes

- **Render free tier** spins down after 15 minutes of inactivity — first request may take ~30s to wake up
- **PostgreSQL free tier** on Render expires after 90 days — export data before then
- Local dev still uses H2 file-based DB — no changes needed locally
